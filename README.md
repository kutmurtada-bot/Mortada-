# نظام توزيع الطحين — GitHub Android

هذا المشروع مبني من ملف الواجهة الأصلي، مع:
- تغيير سنة التوزيع فقط إلى **2026–2040**.
- اسم الحزمة: `com.tahen.app`.
- حفظ ملفات التصدير مباشرة في مجلد **Downloads/التنزيلات** على Android 10+.
- فتح الملف بعد التصدير عند الضغط على تنزيل.
- مشاركة ملفات التصدير عبر Android Share.
- الاحتفاظ ببديل Web Share عند التشغيل خارج التطبيق.
- أيقونة قمح/طحين مخصصة.
- GitHub Actions لبناء APK وAAB.
- دعم توقيع Release عند إضافة أسرار التوقيع إلى GitHub.

## بناء GitHub

1. ارفع المجلد كاملًا إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل **Build Android APK and AAB**.
4. ملف APK التجريبي سيظهر كـ Artifact.
5. لإنتاج نسخة Play موقعة، أضف أسرار التوقيع التالية في Settings → Secrets and variables → Actions:
   - `ANDROID_KEYSTORE_BASE64`
   - `KEYSTORE_PASSWORD`
   - `KEY_ALIAS`
   - `KEY_PASSWORD`

## مهم للتوقيع والنشر
لا تضع ملف keystore أو كلمات المرور داخل المستودع. مفتاح توقيع Google Play هو سر ملكك ويجب الاحتفاظ بنسخة احتياطية منه. ملف AAB الموقّع هو الملف المناسب لرفع تطبيق جديد إلى Google Play.

## Google OAuth
الحزمة مضبوطة على:
`com.tahen.app`

إذا كانت Google Sign-In مستخدمة في نسخة Android أخرى، يجب تسجيل SHA-1 لشهادة التوقيع التي ستستخدمها فعليًا في Google Cloud Console. نسخة debug ونسخة release لهما SHA-1 مختلف غالبًا.

## ملاحظة
هذا المستودع لا يحتوي على keystore حقيقي؛ لذلك لا يمكن أن تكون نسخة Play النهائية موقعة بمفتاحك الخاص من دون أن تضع أسرار التوقيع في GitHub.

## Telegram
- لا يوجد Chat ID مطلوب من المستخدم. أدخل **توكن البوت فقط** في الإعدادات.
- اضغط "حفظ التوكن" وسيحاول التطبيق اكتشاف آخر قروب/مجموعة وصل منها تحديث إلى البوت.
- إذا لم يجد القروب، أضف البوت إلى القروب وأرسل داخله رسالة مثل `/start` أو أي رسالة، ثم اضغط "اكتشاف القروب".
- بعد اكتشاف القروب، يتم حفظ Chat ID محلياً وإرسال إشعارات التسليم مباشرة إلى ذلك القروب.
- لا تضع توكن Telegram داخل GitHub أو داخل ملفات المشروع. خزّنه على الجهاز فقط.
- Telegram Bot API يتطلب `chat_id` عند `sendMessage`، لذلك التطبيق يكتشفه تلقائياً من `getUpdates` بدلاً من طلبه منك يدوياً.
